# ❄ WidgetGame
Мини игра на Qt. 
Генерирует "снежинки" в верхней части игрового поля, которые с некоторой скоростью падают вниз. 
Задача игры не допустить, чтобы снежинки достигли нижнего края игрового поля.
Скорость снежинок случайная, кроме того, скорость менятеся при наведении на снежинку курсором

## ℹ️Цель проекта

* Изучить возможности создания динамического GUI на основе виджетов Qt
* Изучить возможности обрабтки различных событий событий (наведение на виджет, клик на виджет)
